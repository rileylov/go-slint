# go-slint (wip) <a href="https://pkg.go.dev/github.com/rileylov/go-slint#section-documentation" title="go docs" rel="nofollow"><img src="https://img.shields.io/badge/go-documentation-blue.svg?style=flat" alt="go docs"></a>

An alternate take on Go bindings for [Slint](https://slint.dev) inspired by the development process found in [Wails](https://github.com/wailsapp/wails), if you would like to use more faithful bindings that are officially supported, see this [pull request](https://github.com/slint-ui/slint/pull/11308).

## Quickstart

```sh
# Requires Go 1.23+ and a C compiler for cgo
go install github.com/rileylov/go-slint/cmd/goslint@latest

goslint init myapp     # scaffold go.mod + app.slint + main.go + ui/
cd myapp
goslint dev            # run; edit .slint → live in-process reload, edit .go → rebuild
```

## Hello World

```slint
// app.slint
export component HelloWorld inherits Window {
    preferred-width: 280px;
    preferred-height: 180px;
    in property <string> Greeting: "_____";
    callback Greet();

    VerticalBox {
        alignment: center;
        Text {
            horizontal-alignment: center;
            text: root.Greeting + " world";
            font-size: 28px;
        }

        Button {
            text: "Greet!";
            clicked => { root.Greet() }
        }
    }
}
```

```go
// main.go
func main() {
	win, err := ui.NewHelloWorld()
	if err != nil {
		log.Fatal(err)
	}
	defer win.Close()
	win.OnGreet(func() {
		win.SetGreeting("Hello")
	})
	if err := win.Run(); err != nil {
		log.Fatal(err)
	}
}
```
See full example: [`cmd/examples/helloworld`](cmd/examples/helloworld).

> ⚠️ **Warning before using goslint** ⚠️ The majority of the code in this repository was generated by an LLM, the purpose of go-slint is to combine the developer experience of wails and the incredible work of the Slint team to create a library for quick gui development that I will be using for various future GUI projects, **use go-slint at your own risk**.

Ship it:

```sh
goslint build -o myapp .                # one self-contained desktop binary
goslint android build -o myapp.apk .    # signed APK (arm64-v8a + x86_64)
```

run `goslint` or read through the [Guide](DOCS.md) to see the full list of commands.
